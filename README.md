# Ludver Packaging project site

Password-protected project presentation for machinery.ludver.com.

This repository contains the static deployment only: a password screen and encrypted proposal, media, and downloads. Editable source and passwords are not included. The proposal unlocks in the visitor's browser using the existing project password.

GitHub Pages publishes the main branch from the repository root. Replace this deployment with a newly encrypted build to update the presentation; do not upload unencrypted source or media.
